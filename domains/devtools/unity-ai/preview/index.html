Add a folder

Every asset in the folder is listed with the details from its sidecar. Type the path (needs the page served), or browse with the icon (works everywhere).

Files that have a .unityai.json sidecar are shown; the rest stay hidden unless Settings → Library says otherwise.

Add files

Type one path per line (Windows or POSIX, quotes allowed), or browse with the icon. Files added by path keep their location for Copy path and the sidecar; browsed files are located by name and size.

The library lists what the generators wrote: files with a .unityai.json sidecar next to them. Other files in the same folders (a texture Unity extracted, a screenshot) stay out unless Files without a sidecar is on. Files you add yourself always show. Include subfolders lists the folders' subfolders too, each asset captioned with the one it came from. An asset removed from the view stays out of its folder's listing until Show removed brings it back.
